## v25（2026-08-30）: X35の追加除外（KQ2R全ペア／KQ2T異径分岐大／KQ2T・L・D同径品）

くうあつーる再検証（2026-08-28、生成品番1,960件・全33機種を品番確認で突合）で、`x35Applicable()` が
長円形×ミリ系の一部組合せを誤って「成立する」扱いにしていることが判明したため、対象範囲を新規に32件プローブして確定・除外した。

### 確定した追加規則（`x35Applicable()`）
| 対象 | 結果 | 実測の根拠 |
|---|---|---|
| KQ2R（レジューサ、異径全ペア） | 長円形×ミリ系はNG | `KQ2R04-06A1-X35`等9ペア全てNG／真円形`KQ2R04-06A-X35`はOK／`-X12`は同条件でOK |
| KQ2T（両口チーズユニオン・異径チーズ） | **分岐径 > 主管径**の組合せのみNG。分岐径 < 主管径はOK | `KQ2T04-06A1-X35`（分岐06>主管04）＝NG／`KQ2T06-04A1-X35`（分岐04<主管06）＝OK。同様に08⇔04・06⇔10 等で確認 |
| KQ2T・KQ2L・KQ2D の同径品（ねじなし00コード） | 長円形×ミリ系はNG | `KQ2T04-00A1-X35`／`KQ2L04-00A1-X35`／`KQ2D04-00A1-X35`＝いずれもNG |
| KQ2L の異径（レジューサエルボ）・ニップル差込(99・ストリートエルボ) | 対象外（従来どおりOK） | `KQ2L04-06A1-X35`（レジューサエルボ）・`KQ2L04-99A1-X35`（ストリートエルボ）ともOK |
| 長円形×インチ系（同条件） | 対象外（OK） | `KQ2T01-00A1-X35`／`KQ2L01-00A1-X35`／`KQ2L01-03A1-X35`／`KQ2L01-99A1-X35`／`KQ2R01-03A1-X35`＝全てOK |

KQ2X／KQ2XDなど他のC_DIFF機種（KQ2R以外）は長円形の元データ自体が存在しない（roundOnly相当）ため、この規則の対象にならない。

- 検証: 新規プローブ32件（並列1）→ 想定どおりの結果（NG14／OK18）。既存テスト・全数列挙（enumerateAll）は変更なし
- 画面のX35注記・「オーダーメイド記号は…」の注記文（実測日・サンプル件数）を更新済み

## v24（2026-08-18）: オーダーメイド記号の適用範囲を実測で確定

くうあつーる横断監査（生成品番をSMC「品番確認」で突合）で、**オーダーメイド記号を付けた品番が広範囲に成立しない**ことが判明したため、
適用範囲を実測して選択できないようにした。

### 調べ方
ツールが生成しうるオーダーメイド品番 **20,255通り** を全列挙し（`_work/gen_order_pns.mjs`）、
「シール方式×ねじ系×機種×Type×記号×リリースブッシュ形状」の 725 セルから代表2〜3件ずつ **計 2,139 件**を品番確認で突合。
修正後にさらに 868 件・432 件を再突合して効果を確認した。

### 確定した規則（`cleanApplicable()` / `x12Applicable()` / `x35Applicable()`）
| 記号 | 成立する条件 | 実測の根拠 |
|---|---|---|
| `10-`（クリーン） | **真円形のみ**／ねじ付は**材質N**＋（シール剤系ねじは**S必須**・ユニファイ系はシール記号なし）／ねじなしは材質A・N／ニップル・プラグ・カラーキャップは不可 | 長円形はOK 0件。ねじ付 `NS` は全数OK、`A`系（`A`/`AS`）・`AP`/`NP`・`G` は全NG。ユニファイねじの `N` は15/15 OK、Gねじの `N` は9/9 NG。カタログ p.54 の記載例 `10-KQ2H06-02NS`／`10-KQ2H06-00A` と一致 |
| `-X12` | パッキン付（P）は**長円形のみ**（ニップル・プラグは不可）。それ以外は可 | 真円形のパッキン付は `AP`/`NP` とも OK 0件。長円形（`AP1`）はOK |
| `-X35` | 上に加えて**ガスケット付（G）は不可**。機種除外（KQ2H/S/F/E/N/C/P）は従来どおり | `KQ2Y12-04G-X35`／`KQ2D10-04GS-X35`＝NG（`-X12` は同じ形でOK） |

### 残る限界
カタログ p.54 に「**対応機種につきましては別途お問合せください**」とあるとおり、上の規則を満たしても
機種・サイズの組合せ個別に設定が無いことがある（修正後の再突合で 447件中 7件＝1.6%）。
UI にその旨の注意書きを出している。

- 検証: 修正後サンプル **447件中 NG 7件（1.6%）**（修正前は同種のサンプルで 933/2,139＝44%がNG）
- なお「記号の位置が違うのでは」という可能性も確認済み: `KQ2H23-01AP-10`／`KQ2H23-01APX12` などの別置きは
  いずれもNGで、`10-` は先頭・`-X12`/`-X35` は末尾が正しい（＝組合せ自体の設定が無い）
- 生成器: `node _work/gen_order_pns.mjs [対象html]` → `_work/order_pns.txt`
